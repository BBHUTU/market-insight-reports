从商品标题关键词解析（覆盖率 81.4%，剩余归「其他/未识别」）。牙刷、牙膏、牙线为前三，与巴西消费者「基础护理 + 功效升级」双需求吻合。

解读

  • 牙刷是绝对主力：157 个 SKU（31.4%），平价基础款走量，与手动牙刷 30.5% 销量第一互相印证，属「高 SKU 低客单」类目。
  • 功能牙膏成第二主线：82 个 SKU（16.4%），羟基磷灰石、紫管美白（Pasta Roxa）、益生菌等「成分科技」叙事撑溢价。
  • 牙线 + 舌苔清洁构成长尾：合计约 93 个 SKU，巴西消费者对牙缝清洁/口气管理有稳定需求，属高坪效小众。
  • 美白贴少 SKU 高爆发：仅 22 个 SKU 但 CEELIKE 美白贴月销 18,009 居全榜首，属「少 SKU、强单品」品类，爆款驱动明显。
  • 基础护理需靠低价走量：牙刷/牙线/漱口水 SKU 多但溢价空间小，TikTok 巴西站功效型（美白/成分）单品溢价能力更强。

  • 氟化物 + 活性炭并列：各 14 次，活性炭/竹炭的「黑色视觉 + 吸附美白」是巴西特色卖点。
  • 天然/滋养叙事涌现：烟酰胺（11）、蜂蜜（7）、蜂胶（1）等出现，蜂胶为巴西国民天然成分，本土消费者对「天然」接受度高。
  • 美白剂沿单品爆发：过氧化氢/PAP 少量提及但对应美白贴爆品，功效背书正向「口腔微生态/成分科技」延伸。

10总结与选品建议

综合 8 大维度（格局 / 分布 / 类型 / 成分 / 定价 / 头部 / 环比 / 换手），给出可直接落地的选品与投放方向。

  • 主力盘：美白 + 功能牙膏——羟基磷灰石 / 紫管美白（Pasta Roxa）/ 益生菌叙事，定价 R$20–40 撑溢价，CEELIKE、TOYA 已验证爆量。
  • 走量盘：手动牙刷 + 牙线——R$10–20 甜点区，低客单高频复购，OralGos、tang shope br 验证，贡献 30.5%+13.4% 销量。
  • 机会盘：便携护理新品类——口腔喷雾、鼻腔护理（NITEX +12,700%）、牙线棒，周榜新进方向，竞争低、增速高。
  • 成分锚点：薄荷必带——55 商品命中，是巴西市场「默认口味」；蜂胶 / 天然为差异化钩子。
  • 打法：避开 TOYA 双店正面战——TOYA 系合计 38.8% 垄断，新店用「成分差异化 + 强内容（美白对比 / 科普）」切缝隙。
  • 节奏：借放量期冷启——64.4% 环比上升，新品窗口期短，短视频 + 直播双驱动快速试错。
一句话结论：巴西口腔 =「美白 / 功效」溢价 +「牙刷 / 牙线」走量 +「便携护理」增量；平价中端（R$10–40）是主战场，内容驱动的新品在头部垄断下仍有窗口。
